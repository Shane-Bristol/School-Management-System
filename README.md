# School Management System

## Overview

A modern web application built to simplify school administration by managing student records, attendance, grades, teachers, and academic reporting.

## Features

- Authentication
- Student Management
- Teacher Dashboard
- Attendance
- Grades
- Report Cards
- Analytics
- Parent Portal

## Technologies

- Next.js
- TypeScript
- Prisma
- MySQL
- Tailwind CSS
